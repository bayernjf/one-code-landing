# AI Watchdog

> AI Watchdog is a system-tray desktop app that monitors AI coding tools across VS Code, Cursor, Claude, the terminal and other common products in one place. When the AI finishes a task or needs you to take over, it alerts you with sound, desktop notifications and the tray icon. Click the notification to jump straight to the latest file changes. Free, open-source, fully local — no data is ever uploaded.

## Product Definition (Summary)

AI Watchdog is a developer-tool cross-product AI coding monitor for macOS / Windows. It uses file watching and process probing to automatically detect the working state of AI coding tools ("AI working" vs "done") and alerts the developer with sound, desktop notifications and the tray icon when a task completes or human input is needed. Supports a one-click jump to the latest file changes so work continues seamlessly.

## Core Features

1. Cross-product monitoring: monitor VS Code, Cursor, Claude, the terminal and other tools at once — one monitor covers every AI workflow
2. Smart state detection: sliding-window + silence-timeout mechanism distinguishes "AI working" from "done", so you stop guessing
3. Multi-channel alerts: sound + desktop notification + tray icon, so you get notified even away from the editor
4. One-click takeover: click the notification to jump straight to the latest file changes and keep working
5. Activity history: a timeline of AI activity lets you retrace what happened at any time
6. Configurable thresholds: tune silence timeout, activity threshold and window size to fit your rhythm

## Technical Details

- Form: system-tray desktop app (macOS / Windows)
- Runtime: fully local, no data is ever uploaded
- Monitored targets: VS Code, Cursor, Claude, the terminal and other common tools, ticked in Settings
- Platforms: macOS (.dmg), Windows (.exe)
- Distribution: GitHub Releases

## Installation

1. Download the installer for your platform from [GitHub Releases](https://github.com/bayernjf/one-code/releases)
2. Open the app; the AI Watchdog tray icon appears
3. Tick the tools you want to watch in Settings, and you are set
