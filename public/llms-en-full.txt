# AI Watchdog — Full Documentation (English)

## Product Definition

AI Watchdog is a cross-product AI coding monitor desktop app (macOS / Windows) that lives in the system tray and watches the working state of AI coding tools, notifying you to take over at the right moment.

It belongs to the developer-tools category. The core problem it solves: when AI coding assistants (such as Copilot, Cursor, Claude) are writing code automatically, developers often switch away to do other things — and they don't know when the AI finishes, whether it hit a problem, or whether human input is needed. AI Watchdog detects the AI's working state through file watching and process probing, and alerts the developer via sound, desktop notifications and the tray icon when it's time to take over.

## How It Works

### 1. Cross-Product Monitoring

AI Watchdog monitors several common AI coding tools (VS Code, Cursor, Claude, the terminal, etc.) at once — one monitor covers every AI workflow. Targets are ticked in the Settings window and toggled independently.

It detects AI activity through two kinds of signals:
- File watching: listens for changes within the watched directories
- Process probing: polls the target software's process activity as a weak secondary signal

It ignores node_modules, .git, dist, build, .next, coverage, __pycache__, target directories by default.

### 2. Sliding-Window State Detection

The core detection mechanism is a sliding-window counter:
- Within a time window (default 3 seconds), if file changes reach a threshold (default 3), the AI is judged "working"
- When AI activity stops beyond a silence timeout (default 8 seconds), it is judged "done" and a notification fires

All thresholds (silence timeout, activity threshold, window size) are adjustable in the app's Settings window.

### 3. Multi-Channel Notifications

When the AI state transitions to "done", AI Watchdog notifies via three channels:
- Sound alert: adjustable volume
- Desktop system notification: triggered when the app is not in the foreground, using OS-native notifications
- Tray icon: reflects the current AI working state in real time

### 4. One-Click Takeover

When you receive a notification, clicking it automatically locates the most recently modified file so you can resume work quickly.

## Monitored Tools

- VS Code: monitors file operations by VS Code and its AI extensions
- Cursor: monitors file operations in the Cursor editor
- Claude: monitors activity in the Claude desktop app
- Terminal: monitors terminal output changes

Each monitor can be toggled independently in Settings.

## Privacy & Security

AI Watchdog runs entirely locally:
- No telemetry data collected
- No file contents or paths uploaded
- No network communication (apart from downloading the installer from GitHub Releases)
- All state detection and notifications happen on the local machine

## Default Settings

| Parameter | Default | Description |
|-----------|---------|-------------|
| Silence timeout | 8s | Wait time before judging the AI done |
| Activity threshold | 3 | Changes in the window that trigger "working" |
| Window size | 3s | Sliding window size |
| Sound | On | Adjustable volume |

## Installation

1. Download the installer for your platform from GitHub Releases (macOS .dmg / Windows .exe)
2. Open the app; the AI Watchdog tray icon appears
3. Tick the tools you want to watch in Settings, and you are set

## FAQ

Q: Which AI coding tools does AI Watchdog monitor?
A: It monitors VS Code, Cursor, Claude, the terminal and other common products in one place. Each monitor can be toggled independently in the Settings window.

Q: Does it collect or upload my data?
A: No. AI Watchdog runs entirely locally. All file-change monitoring, state detection and notifications happen on your machine — nothing is collected or uploaded.

Q: How does it detect whether the AI is working or done?
A: Via a sliding-window mechanism: if file changes reach a threshold (default 3) within a time window (default 3 seconds), the AI is judged "working". When activity stops beyond a silence timeout (default 8 seconds), it is judged "done" and a notification fires.

Q: What notification channels are available?
A: Three channels: sound alert (adjustable volume), desktop system notification (when the app is not in the foreground), and tray icon status. Each can be toggled independently.

Q: Which platforms are supported?
A: macOS (.dmg) and Windows (.exe). It works via file watching and process probing with negligible overhead, excluding node_modules, dist, .git and similar directories by default.

Q: How do I install it?
A: Download the installer for your platform from GitHub Releases, open the app (tray icon appears), and tick the tools to watch in Settings.

Q: Will it impact system performance?
A: No. AI Watchdog uses lightweight file watching and sliding-window counting with minimal memory and CPU usage. It excludes node_modules, dist, .git and similar directories by default to avoid unnecessary overhead.
